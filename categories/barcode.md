# BarCode

| API | Description | Link |
|:---|:---|:---|
| Dynamic QR Code | Generate dynamic and static QR Codes. | [Link](https://rapidapi.com/updeploy-tools/api/qr-code-dynamic-and-static1/details) |
| Google Barcode | The Barcode API detects barcodes in real-time, on device, in any orientation. It can also detect multiple barcodes at once. | [Link](https://developers.google.com/vision/barcodes-overview?hl=en) |
| EAN-Search | The EAN-Search API allows you to lookup products by EAN, UPC or GTIN barcode. | [Link](https://www.ean-search.org/ean-database-api.html) |
| QR Code API | QR Code REST API. Can create QR code images or read existing images and return the contents. | [Link](https://fungenerators.com/api/qrcode/) |
| QR Code Generator API | Static and Dynamic QR code generator API | [Link](https://docs.openqr.io/) |
| Stakdek's QR Generator API | Returns QR code image. Uses `python qrcode`. | [Link](https://api.stakdek.de/blog?id=1006) |
