# File Storage and Manipulation

| API | Description | Link |
|:---|:---|:---|
| Amazon S3 | API that provides access to stored files and can be added easily to any service - and it's free for twelve months. | [Link](https://aws.amazon.com/de/documentation/s3/) |
| Cloudinary | API for image and video storage and manipulation - free for up to 75,000 images and 7,500 manipulations per month, good documentation. It can also manipulate GIFs and PDFs. | [Link](http://cloudinary.com/documentation) |
| DigitalOcean Spaces | API that provides easy access to store and receive files as simple object storage with easy to understand pricing. 2 Month Free Trial | [Link](https://www.digitalocean.com/products/spaces) |
| Filestack | API for image and file manipulation, 250 uploads and 500 uploads per month for free, free CDN, HTML widget. | [Link](https://filestack.com/docs/) |
| Microsoft Graph | API for accessing stored files and photos for personal and enterprise users with high resolution thumbnails and Microsoft Office APIs. | [Link](https://graph.microsoft.io/en-us/docs/api-reference/v1.0/resources/onedrive) |
| PDF Blocks | API for working with PDF documents (merge, add password, watermark, and more). Well documented, easy to use. 14-day free trial. | [Link](https://www.pdfblocks.com/docs/api/getting-started) |
| SignNow API – eSign API by airSlate | Embed branded eSignature workflows in your app and quickly customize them to your user needs. | [Link](https://docs.signnow.com/docs/signnow/welcome) |
| Smash | Smash API & SDK to upload large files on websites, mobile apps, SaaS solutions and custom workflows. | [Link](https://api.fromsmash.com/) |
| Vector Express | API for converting, processing and analyzing vector files. | [Link](https://github.com/smidyo/vectorexpress-api) |
| Verizon Cloud | API for accessing stored pictures and other files stored by users of Verizon Cloud app. | [Link](http://www.verizon.com/cloudstorageapi) |
| Vertopal | The Vertopal API lets you convert files to a variety of formats. | [Link](https://www.vertopal.com/en/developer/api/introduction) |
