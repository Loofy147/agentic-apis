# News Services

| API | Description | Link |
|:---|:---|:---|
| Faroo | Alternative to Google Web Search API / Google News Search API, allows you to search news within dates, fetch trending news, topics and terms. | [Link](http://www.faroo.com/hp/api/api.html) |
| Mediastack | Scalable [JSON](https://en.wikipedia.org/wiki/JSON) API delivering worldwide news, headlines and blog articles in real-time. | [Link](https://mediastack.com/documentation) |
| New York Times | Article search, best sellers, campaign finance, community, most popular, real estate, movie reviews, NY state legislature, Times newswire, tags, and people. | [Link](http://developer.nytimes.com/) |
| NewsCatcherAPI | News API to find news articles by any topic, country, language, website or keyword. | [Link](https://newscatcherapi.com/news-api) |
| RSS API | API to parse and subscribe to RSS Feeds to get webhooks when new items are published. | [Link](https://docs.rssapi.net) |
