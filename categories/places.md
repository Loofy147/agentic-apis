# Places

| API | Description | Link |
|:---|:---|:---|
| CountryAPI | Get all the countries, and obtain the most important information of these. | [Link](https://fabian7593.github.io/CountryAPI/) |
| Factual | Providing a places search that can be searched by latitude/longitude, and “where” using full text search query string. | [Link](https://developer.factual.com/docs/getting-started) |
| Foursquare Venue | Providing a places search that can be searched by  hierarchical list of categories, longitude/latitude etc. | [Link](https://developer.foursquare.com/overview/venues) |
| Google Places API | Providing a places search that can be searched by latitude/longitude, keyword matched against all fields, name of place, type of place restricted by radius. | [Link](https://developers.google.com/maps/documentation/places/web-service/overview) |
| Nokia | Providing a JavaScript places search that can be searched by search term, with a detail search for display by JS widget. | [Link](https://developer.here.com/develop/javascript-api) |
| World Wonders API | Provides information about famous wonders from around the world. | [Link](https://github.com/Rolv-Apneseth/world-wonders-api) |
| Yelp | You can search location using longitude and latitude, neighborhood, address or city and filter listings by “where”, using a list of support categories. | [Link](https://docs.developer.yelp.com/docs/getting-started) |
